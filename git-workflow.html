Git 分支策略与提交规范 ​

本文档定义项目的 Git 分支管理策略、提交信息规范及版本标签管理方案。

目录 ​

  • 分支策略
  • 提交信息规范
  • 版本标签管理
  • 代码审查流程
  • 紧急修复流程

分支策略 ​

分支模型 ​

main (stable)
  │
  ├── develop (integration)
  │     │
  │     ├── feature/add-user-auth
  │     ├── feature/upgrade-react-19
  │     └── fix/login-redirect-loop
  │
  ├── release/v1.2.0
  │
  └── hotfix/security-patch

分支说明 ​

分支用途生命周期保护规则
main生产环境稳定代码永久禁止直接 push，需 PR + 2 approvals
develop开发集成分支永久禁止直接 push，需 PR + 1 approval
feature/*功能开发短期（< 2 周）无保护，可 force push
fix/*bug 修复短期（< 1 周）无保护
release/*发布准备短期（< 3 天）仅允许 bug fix，禁止新功能
hotfix/*紧急修复极短（< 1 天）需快速 review

分支命名规范 ​

前缀格式示例使用场景
feature/feature/描述feature/add-dark-mode新功能开发
fix/fix/描述fix/login-crash非紧急 bug 修复
hotfix/hotfix/描述hotfix/security-xss生产环境紧急修复
release/release/版本号release/v1.2.0发布准备
chore/chore/描述chore/update-deps构建/依赖更新
docs/docs/描述docs/update-readme文档更新
refactor/refactor/描述refactor/simplify-api代码重构
perf/perf/描述perf/optimize-render性能优化
test/test/描述test/add-e2e测试相关

提交信息规范 ​

Conventional Commits 格式 ​

<type>(<scope>): <subject>

<body>

<footer>

Type 类型 ​

类型含义版本 bump示例
feat新功能MINORfeat(ui): add dark mode toggle
fix修复 bugPATCHfix(api): handle null pointer
docs文档更新无docs: update setup guide
style代码格式无style: fix indentation
refactor重构无refactor(utils): simplify deepClone
perf性能优化PATCHperf(build): enable tree shaking
test测试相关无test(ui): add Button test cases
chore构建/工具链无chore: upgrade pnpm to 8.15
ciCI/CD 变更无ci: add GitHub Actions cache
revert回滚提交PATCHrevert: feat(ui): add dark mode

Scope（范围） ​

使用包名或模块名作为 scope：

bash
feat(ui): add Button loading state
fix(api): resolve CORS issue
docs(setup): add Node.js version requirement
chore(deps): upgrade typescript to 5.3.3

Subject（主题） ​

  • 使用祈使句（imperative mood）
  • 首字母小写
  • 不超过 50 个字符
  • 不以句号结尾
bash
# 好
feat(ui): add Button loading state

# 差
feat(ui): Added Button loading state.
feat(ui): adds button loading state

Body（正文） ​

  • 详细说明变更原因和影响
  • 与 subject 空一行
  • 每行不超过 72 个字符
bash
feat(ui): add Button loading state

- 新增 loading 属性，显示 spinner
- 禁用按钮防止重复提交
- 兼容所有现有 variant

Closes #123

Footer（脚注） ​

bash
# 关联 Issue
Closes #123
Fixes #456
Refs #789

# 破坏性变更
BREAKING CHANGE: Button 的 type 属性改为 variant

# 共同作者
Co-authored-by: Name <email@example.com>

完整示例 ​

bash
feat(auth): implement OAuth2 login flow

- 新增 Google OAuth2 登录支持
- 添加 refresh token 自动续期
- 登录状态持久化到 localStorage

Closes #234
BREAKING CHANGE: 登录接口返回格式从 { token } 改为 { accessToken, refreshToken }

版本标签管理 ​

标签命名规范 ​

类型格式示例使用场景
正式版vX.Y.Zv1.2.0生产发布
预发布vX.Y.Z-beta.Nv1.2.0-beta.1公开测试
候选版vX.Y.Z-rc.Nv1.2.0-rc.1发布候选
内部版vX.Y.Z-alpha.Nv1.2.0-alpha.1内部测试

创建标签 ​

bash
# 创建带注释的标签（推荐）
git tag -a v1.2.0 -m "Release v1.2.0: add dark mode and performance improvements"

# 创建轻量标签（不推荐）
git tag v1.2.0

# 推送标签到远程
git push origin v1.2.0

# 推送所有标签
git push origin --tags

标签策略 ​

bash
# 从 main 分支创建正式版标签
git checkout main
git pull origin main
git tag -a v1.2.0 -m "Release v1.2.0"
git push origin v1.2.0

# 从 release 分支创建预发布标签
git checkout release/v1.2.0
git tag -a v1.2.0-beta.1 -m "Beta release for testing"
git push origin v1.2.0-beta.1

代码审查流程 ​

PR 创建 ​

bash
# 1. 创建功能分支
git checkout -b feature/add-dark-mode develop

# 2. 提交代码
git add .
git commit -m "feat(ui): add dark mode toggle"

# 3. 推送分支
git push origin feature/add-dark-mode

# 4. 创建 PR
gh pr create --title "feat(ui): add dark mode toggle" \
  --body "实现暗色模式切换功能，包含：
- 主题切换按钮组件
- localStorage 持久化
- 系统偏好自动检测

Closes #123"

PR 审查清单 ​

  • [ ] 代码符合项目规范
  • [ ] 包含必要的测试
  • [ ] 文档已更新
  • [ ] 无 console.log 等调试代码
  • [ ] 无敏感信息泄露
  • [ ] 性能影响已评估

合并策略 ​

策略命令优点缺点
Mergegit merge --no-ff保留完整历史历史线复杂
Squashgit merge --squash历史简洁丢失提交细节
Rebasegit rebase develop线性历史需协调冲突

推荐策略：

  • feature/* -> develop: Squash and merge
  • develop -> main: Merge commit
  • hotfix/* -> main: Rebase and merge

紧急修复流程 ​

bash
# 1. 从 main 创建 hotfix 分支
git checkout main
git checkout -b hotfix/security-patch

# 2. 修复并提交
git commit -m "fix(security): patch XSS vulnerability"

# 3. 创建标签
git tag -a v1.2.1 -m "Hotfix: security patch"

# 4. 合并回 main 和 develop
git checkout main
git merge --no-ff hotfix/security-patch
git push origin main --tags

git checkout develop
git merge --no-ff hotfix/security-patch
git push origin develop

# 5. 删除 hotfix 分支
git branch -d hotfix/security-patch
