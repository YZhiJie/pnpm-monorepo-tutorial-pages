学习路径 ​

本教程按「由浅入深」分为五篇，建议从入门篇顺序推进；每篇结尾都指向下一篇，形成闭环。

阶段章节你会得到
🌱 入门篇01 为什么选择 pnpm Monorepo、02 环境搭建、03 工作区配置建立认知，跑通第一个 monorepo
🚀 进阶篇04 包创建与依赖声明、05 依赖共享与 Hoisting、06 workspace 协议能独立设计包结构与依赖关系
🏗️ 高级篇07 构建与缓存、08 版本发布、09 CI/CD、10 Git 协作能落地完整工程化流水线
🔬 原理篇P1 store 与符号链接、P2 lockfile、P3 peer/hoisting、P4 拓扑构建、P5 版本计算理解实现原理，遇到问题能定位根因
🧪 练习篇E1 workspace 范围、E2 协议语义、E3 幻影依赖、E4 拓扑调度、E5 版本 bump亲手实现核心算法，达到随心自定义
