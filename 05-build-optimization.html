构建工具集成 ​

TypeScript (tsc) 集成 ​

json
// packages/utils/package.json
{
  "scripts": {
    "build": "tsc -p tsconfig.build.json",
    "build:watch": "tsc -w"
  }
}
json
// packages/utils/tsconfig.build.json
{
  "extends": "../../tsconfig.json",
  "compilerOptions": {
    "outDir": "dist",
    "declaration": true,
    "sourceMap": true,
    "noEmit": false
  },
  "include": ["src/**/*"],
  "exclude": ["**/*.test.ts", "**/*.spec.ts"]
}

Vite 集成（库模式） ​

ts
// packages/ui/vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import dts from "vite-plugin-dts";

export default defineConfig({
  plugins: [
    react(),
    dts({ insertTypesEntry: true }), // 生成类型声明
  ],
  build: {
    lib: {
      entry: "src/index.ts",
      name: "TutorialUI",
      formats: ["es", "cjs"],
      fileName: (format) => `index.${format}.js`,
    },
    rollupOptions: {
      external: ["react", "react-dom"],
      output: {
        globals: { react: "React", "react-dom": "ReactDOM" },
      },
    },
  },
});

Webpack 集成 ​

js
// packages/ui/webpack.config.js
module.exports = {
  entry: "./src/index.ts",
  output: {
    library: "TutorialUI",
    libraryTarget: "umd",
    filename: "index.js",
  },
  externals: {
    react: "react",
    "react-dom": "react-dom",
  },
  resolve: { extensions: [".ts", ".tsx"] },
  module: {
    rules: [{ test: /\.tsx?$/, use: "ts-loader", exclude: /node_modules/ }],
  },
};

增量构建实现 ​

TypeScript 项目引用（Project References） ​

json
// tsconfig.json
{
  "references": [
    { "path": "packages/types" },
    { "path": "packages/utils" },
    { "path": "packages/ui" }
  ]
}

// packages/utils/tsconfig.json
{
  "references": [{ "path": "../types" }],
  "compilerOptions": {
    "composite": true,
    "tsBuildInfoFile": "node_modules/.tmp/tsconfig.tsbuildinfo"
  }
}

构建命令：

bash
# 仅构建变更的包及其依赖
tsc --build

# 强制全量重建
tsc --build --force

Turbo / Nx 集成（推荐大型项目） ​

json
// turbo.json
{
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"],
      "inputs": ["src/**", "tsconfig.json"]
    },
    "test": {
      "dependsOn": ["build"],
      "outputs": [],
      "inputs": ["src/**", "test/**"]
    }
  }
}

构建缓存配置 ​

本地缓存目录 ​

ini
# .npmrc
# 缓存目录：存储下载的 tarball 和元数据
cache-dir=~/.pnpm-cache

# Store 目录：内容寻址存储
store-dir=~/.pnpm-store

构建工具缓存 ​

json
// vite.config.ts
export default defineConfig({
  build: {
    cacheDir: 'node_modules/.vite', // Vite 缓存
  },
});
json
// turbo.json
{
  "cacheDir": ".turbo/cache" // Turbo 缓存
}

CI 缓存策略（GitHub Actions） ​

yaml
- name: Cache pnpm modules
  uses: actions/cache@v3
  with:
    path: |
      ~/.pnpm-store
      node_modules
      .turbo
    key: ${{ runner.os }}-pnpm-${{ hashFiles('**/pnpm-lock.yaml') }}
    restore-keys: |
      ${{ runner.os }}-pnpm-

多包并行构建策略 ​

pnpm 原生并行 ​

bash
# 并行构建所有包（默认按拓扑顺序）
pnpm -r --parallel run build

# 限制并发数（默认 4）
pnpm -r --parallel --workspace-concurrency=4 run build

# 仅构建有变更的包（基于依赖图）
pnpm -r --filter ...[origin/main] run build

拓扑排序构建 ​

bash
# 按依赖拓扑顺序构建（串行但保证依赖先构建）
pnpm -r run build

# 并行构建（忽略拓扑，需确保依赖已构建）
pnpm -r --parallel run build

条件构建 ​

bash
# 仅构建有 build 脚本的包
pnpm -r --if-present run build

# 仅构建特定目录
pnpm -r --filter ./packages/* run build

# 构建依赖 @tutorial/ui 的所有包
pnpm -r --filter ...@tutorial/ui run build

构建性能优化 ​

1. 排除测试文件 ​

json
// tsconfig.build.json
{
  "exclude": ["**/*.test.ts", "**/*.spec.ts", "**/__tests__/**"]
}

2. 减少声明文件生成 ​

json
// 开发环境跳过类型检查
{
  "compilerOptions": {
    "skipLibCheck": true,
    "declaration": false // 仅生产构建生成 .d.ts
  }
}

3. 使用 esbuild/swc 替代 tsc ​

bash
# 安装 esbuild
pnpm add -D esbuild

# 构建脚本
esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm

4. 并行类型检查 ​

json
// package.json
{
  "scripts": {
    "build": "vite build",
    "typecheck": "tsc --noEmit" // 与构建并行执行
  }
}
