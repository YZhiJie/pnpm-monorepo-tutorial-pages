练习篇导读 ​

读到这里，你已经理解了 pnpm monorepo 的用法与原理。这一篇是动手环节：五个练习把前面讲过的内核概念，各自抽象成一个纯 TypeScript 函数，让你亲手写一遍。

写得出，才叫真懂。

为什么用「纯函数」练习 ​

真实的 pnpm 装包过程依赖磁盘、网络与大量环境差异，很难在几分钟内复现。所以我们把内核逻辑抽出来：

  • 练习代码全是纯 TypeScript 函数，不依赖真实安装，任何环境 vitest 一跑就出结果；
  • 每个练习都配了测试用例（不用你写）与参考答案（卡住就看）；
  • 练完之后，再回到真实仓库里验证——你会发现自己读得懂 node_modules 和 pnpm-lock.yaml 了。

前置准备 ​

练习代码位于仓库的 exercises/ 目录，已纳入 pnpm workspace：

bash
# 在仓库根安装依赖（会同时链接 exercises/* 各包）
pnpm install

每个练习怎么练 ​

假设你从 E1 开始：

bash
# 1. 打开习题文件，按注释与提示实现 TODO
#    exercises/exercise-01-workspace-scope/src/index.ts

# 2. 跑你自己的实现
pnpm --filter @tutorial/exercise-01 test:mine

# 3. 卡住了？跑参考答案对照（会绿）
pnpm --filter @tutorial/exercise-01 test

💡 默认脚本 test 带 --mode answer，会把测试里的 ./index 换成 answers/reference.ts， 所以仓库与 CI 永远是绿的；学习者自测请用 test:mine。

一次跑完五个练习（含参考答案）：

bash
pnpm -r --filter "./exercises/*" test

阅读建议 ​

  • 先自己做，至少卡住 15 分钟再看答案——否则「看懂了」是错觉；
  • 做完回原理篇，把练习里的函数与真实 node_modules / pnpm-lock.yaml 对照，形成闭环；
  • 改一遍测试：加自己的边界用例，这是从「会做」到「掌握」的分水岭。

目录约定 ​

exercises/exercise-0X-xxx/
├── src/index.ts          # 你实现的地方（TODO 桩）
├── src/index.test.ts     # 测试用例（不用改）
├── answers/reference.ts  # 参考答案
├── vitest.config.ts      # --mode answer 的别名机制
├── tsconfig.json
└── package.json
