E1 · 解析 workspace 范围 ​

前置：03 工作区配置与目录设计　|　习题目录：exercises/exercise-01-workspace-scope/

pnpm-workspace.yaml 用 glob 声明「哪些目录是 workspace 包」。这个匹配规则看起来简单，但 ** 能匹配零个或多个路径段这一点，很容易实现错。本练习让你亲手写一遍。

你将实现 ​

在 src/index.ts 中实现两个函数：

ts
/** 通配符匹配：`*` 匹配单段内任意字符（不含 `/`），`**` 匹配零个或多个路径段。 */
export function matchesGlob(path: string, pattern: string): boolean;

/**
 * 判断某个包目录是否属于 workspace。
 * @param dir      包目录，相对仓库根、以 `/` 分隔（如 `"apps/web"`）
 * @param patterns 纳入规则（如 `["apps/*", "packages/*"]`）
 * @param excludes 排除规则（如 `["**&#47;test/**"]`）；命中即排除，优先级高于纳入规则
 */
export function isInWorkspace(
  dir: string,
  patterns: string[],
  excludes?: string[],
): boolean;

规则与提示 ​

  • 先把路径与 glob 都按 / 拆成「段」，再逐段比较；

  • * 只匹配单个段内的任意字符，不跨 /：

    text
    matchesGlob("apps/web", "apps/*")      // true
matchesGlob("apps/web/src", "apps/*")  // false —— 多了一层

  • ** 匹配零个或多个段——注意「零个」：

    text
    matchesGlob("packages", "packages/**")               // true  —— `**` 吃了 0 段
matchesGlob("packages/ui/src/main.ts", "packages/**") // true

  • 排除规则优先于纳入规则：命中任一 exclude 即判为不在 workspace。

运行 ​

bash
pnpm --filter @tutorial/exercise-01 test:mine   # 跑你的实现
pnpm --filter @tutorial/exercise-01 test        # 跑参考答案

参考答案 ​

点开查看参考实现

思路：把路径与 glob 都拆成段数组，用动态规划解决 ** 的「匹配零段」问题。

  • dp[i][j] = path 的前 i 段能否被 pattern 的前 j 段匹配；
  • pattern 段是 **：dp[i][j] = dp[i][j-1]（** 不吃段）|| dp[i-1][j]（** 吃一段）；
  • pattern 段是普通段：dp[i][j] = dp[i-1][j-1] && 该段匹配。

单段内的 * 用「按 * 切分 + 前后缀 + 顺序查找」判断，避免正则转义带来的边界 bug。

ts
/** 单段内的通配匹配：`*` 可匹配任意长度字符（含空），但不跨 `/`（此处已按段切好）。 */
function matchSegment(seg: string, pat: string): boolean {
  const parts = pat.split("*");
  if (parts.length === 1) return seg === pat;

  const head = parts[0];
  if (!seg.startsWith(head)) return false;
  let cursor = head.length;

  for (let i = 1; i < parts.length - 1; i++) {
    const part = parts[i];
    if (part === "") continue;
    const found = seg.indexOf(part, cursor);
    if (found === -1) return false;
    cursor = found + part.length;
  }

  const tail = parts[parts.length - 1];
  return seg.length - tail.length >= cursor && seg.endsWith(tail);
}

export function matchesGlob(path: string, pattern: string): boolean {
  const pathSegs = path.split("/").filter(Boolean);
  const patSegs = pattern.split("/").filter(Boolean);

  const dp: boolean[][] = Array.from({ length: pathSegs.length + 1 }, () =>
    new Array<boolean>(patSegs.length + 1).fill(false),
  );
  dp[0][0] = true;

  // pattern 开头的连续 `**` 可以吃掉 0 段
  for (let j = 1; j <= patSegs.length; j++) {
    if (patSegs[j - 1] === "**" && dp[0][j - 1]) dp[0][j] = true;
    else break;
  }

  for (let i = 1; i <= pathSegs.length; i++) {
    for (let j = 1; j <= patSegs.length; j++) {
      const pat = patSegs[j - 1];
      if (pat === "**") {
        dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
      } else {
        dp[i][j] = dp[i - 1][j - 1] && matchSegment(pathSegs[i - 1], pat);
      }
    }
  }

  return dp[pathSegs.length][patSegs.length];
}

export function isInWorkspace(
  dir: string,
  patterns: string[],
  excludes: string[] = [],
): boolean {
  if (excludes.some((pattern) => matchesGlob(dir, pattern))) return false;
  return patterns.some((pattern) => matchesGlob(dir, pattern));
}

延伸思考 ​

  • 真实 pnpm 用的匹配库是 @pnpm/matcher，内部走的是 minimatch 系语义。你的实现与它在 ** 语义上一致吗？
  • 打开本仓库的 pnpm-workspace.yaml，看看 packages/*、apps/* 与 !**/test/** 各起什么作用，再拿本练习的函数去「模拟匹配」一遍。
